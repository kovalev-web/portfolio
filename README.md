# fraimye — новый сайт (каркас главной)

Каркас главной страницы, собранный по мотивам davidhaz.com.
Разбор референса — в [REFERENCE.md](REFERENCE.md).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
```

## Стек

React 19 + TypeScript + Vite, обычный CSS с custom properties, сырой WebGL
для градиентов. Внешних рантайм-зависимостей, кроме React, нет.

Прод-бандл: **67 KB gzip JS + 4 KB gzip CSS**.


## Шапка: вырез и его филеты

Логотип живёт в вырезе, «прогрызенном» в углу hero-карточки. Шапка просто
`position: fixed` и **не меняется при скролле** — ровно как на референсе,
где `.header-logo-box` тоже фиксированный и залит цветом фона. Никакой
логики состояний тут нет и быть не должно.

Заливка выреза непрозрачная (`var(--bg)`) на всех ширинах — именно она
не даёт логотипу столкнуться с заголовком секции, который проезжает под
ним. На мобильном вырез превращается в сплошную полосу на всю ширину, а
hero получает `padding-top: calc(var(--header-h) + 10px)`, чтобы полоса
не накрывала карточку.

> ⚠️ **На `.notch` нельзя вешать `border` — даже прозрачный.** При
> `box-sizing: border-box` бордер сдвигает padding-box, а вогнутые филеты
> позиционируются от него (`top: 100%`, `left: 100%`). Один пиксель бордера
> уводит оба филета из выравнивания и оставляет видимые полоски вдоль края
> карточки. То же относится к `.hero-copy` и его `::after`.

Оба филета сделаны на 1px больше со стороны, обращённой к сплошному блоку,
и на тот же 1px сдвинуты назад — сглаженный край радиального градиента
перекрывается сплошной заливкой и шва не остаётся. Окружность при этом
остаётся привязанной к углу бокса, так что дуга не меняется.

**Филеты видны только на самом верху** (`useAtTop` → `data-at-top`). Они
мостят вырез к краям карточки, а шапка фиксированная — карточка уезжает
из-под неё, и филеты повисают над ней чёрными клювами. На референсе ровно
та же проблема есть, просто её не видно: их nav-пилюля стоит вплотную к
логотипу и накрывает филет собой. Наша по макету улетела вправо, поэтому
филет оказывается голым на карточке.

Гаснут **только** эти две угловые фигуры. Сам блок с аватаром и именем не
меняется никогда — ни размера, ни формы, ни фона.

Nav-пилюля (`.nav-pill`) стеклянная — полупрозрачный блюр читается и на
синей карточке, и на любой секции ниже.

## Hero на мобильном: без наложений

Десктопная композиция (медиа абсолютным позиционированием поверх карточки
фиксированной высоты, заголовок в вырезе снизу-слева) держится на том, что
карточка намного выше своего контента. На мобильном высота становится
`auto`, и та же математика даёт две поломки: `.hero-media` с
`bottom: -7%`, унаследованным без сброса, вылезает за карточку; а
`.hero-copy` шириной 92% оставляет оголённый скруглённый угол карточки
справа, раз медиа там уже не сидит.

Вместо починки процентов — на `≤860px` composition меняется на обычный
вертикальный стек: `.hero-card` становится `flex-direction: column`,
`.hero-media` — `position: static` с `aspect-ratio`, `.hero-copy` — 100%
ширины без выреза. Никакой абсолютной математики, поэтому и ломаться
нечему.

## Анимации

**Blur-in на скролле.** Класс `.reveal` (`blur(12px) → 0`), для крупного текста
`.reveal-lg` (`blur(26px)`). Стаггер задаётся инлайн-переменной `--d`.
Один общий IntersectionObserver в `useReveal`, элемент раскрывается один раз.

**Ховеры.**

| Где | Что |
|---|---|
| Список работ | строка уезжает вправо, линия темнеет, соседние гаснут до 0.35, превью летит за курсором, курсор — SVG-стрелка (инвертируется в тёмной теме) |
| Скиллы | медиа раскрывается по ховеру (не только по скроллу), соседние строки гаснут |
| Фото в About | `scale(1.05)` |
| Опыт работы | строка уезжает вправо, соседние гаснут до 0.45, плюс превращается в минус поворотом на 180° |
| star-button | заливка инвертируется, ✦ мигают |

> ⚠️ `transition` — шорткат. Если элемент одновременно `.reveal` и имеет свой
> `transition`, свойства блюр-ина (`filter`, `opacity`, `transform`) надо
> перечислить в компонентном правиле, иначе они потеряются. Поэтому
> `base.css` импортируется **первым** — компонентные стили должны выигрывать.
> Так сделано в `.work-row`, `.scroll-cue`, `.star-button`.

## Что настроить дальше

1. **Шрифт.** Сейчас General Sans с CDN Fontshare (ближайшая бесплатная замена
   Matter из референса). Перед проливкой — скачать `woff2` и положить в
   `public/fonts`, убрать `<link>` из `index.html`.

2. **Скрин в hero.** Положить файл по пути из `heroMedia.src`
   (`public/media/hero.png`) — плейсхолдер подменится сам, править код не надо.
   Картинка обрезается по нижнему краю карточки, поэтому важен верх кадра
   (`object-position: top center`).

3. **Остальные медиа.** Плейсхолдеры-градиенты в `.work-preview`,
   `.about-media-fill`, `.skill-media-fill` — помечены комментариями.

4. **Контент.** Тексты и списки — в `src/data/content.ts`, компоненты трогать
   не нужно. Опыт работы — массив `experience`, логотипы лежат в
   `public/media/logos`. Если файла нет, плитка покажет инициалы из поля
   `initials`.

5. **Skills & services** — секция отключена, но не удалена: раскомментировать
   импорт и `<Skills />` в `src/App.tsx`.

6. **Роутинг.** Каркас — одна страница. Под кейсы (`/work/trade-scope` и
   остальные из `projects`) понадобится роутер; пока это просто ссылки.

7. **Палитры шейдера.** Массив из четырёх hex в `Hero.tsx` и `Contact.tsx`.

## Заметки по производительности

- Шейдер — один полноэкранный треугольник, DPR ограничен 1.5.
- Рендер останавливается, когда карточка вне вьюпорта, когда вкладка в фоне
  и при `prefers-reduced-motion`.
- `preserveDrawingBuffer: true` нужен именно из-за остановки цикла: без него
  буфер очищается на следующем композите и карточка чернеет.
- Зерно рисуется 180×180 и растягивается CSS-ом, ~12 fps.
