# davidhaz.com — разбор референса

Всё ниже получено из живого сайта: бандл `assets/index-CqHGUZP5.js` (487 KB),
`assets/index-DJzGRS-X.css` (36 KB), DOM-дерево и сетевые запросы.

## Стек

| Что | Чем | Как проверено |
|---|---|---|
| Сборка | **Vite** | хешированные `assets/index-[hash].js/css`, `<script type="module" crossorigin>` |
| Рендер | **React 18.3.1**, CSR | строка `"18.3.1"` в бандле, `createRoot`, в HTML пустой `<div id="root">` — SSR нет |
| Стили | **обычный CSS**, один файл | семантические классы (`.hero-left`, `.skill-section`), ни одного `--tw-`, нет `@layer` |
| Анимации | **CSS transitions + IntersectionObserver** | 5 × `IntersectionObserver`, 34 × `requestAnimationFrame`; GSAP / Framer Motion / Lenis **отсутствуют** |
| Графика | **сырой WebGL**, без библиотек | `getContext("webgl")`, `createProgram`, `gl_FragColor`; three.js / OGL в бандле нет |
| Слайдеры | **Swiper 11** web-components | `<script src="cdn.jsdelivr.net/npm/swiper@11/swiper-element-bundle.min.js">` |
| Шрифт | **Matter** (коммерческий), 6 начертаний | `@font-face` c `.ttf` (не woff2 — упущенная экономия ~40%) |
| Медиа | `.mp4` + `.webp`-плейсхолдеры | по одному mp4 на каждый блок скиллов |
| Хостинг | статика + GA4 | `gtag/js?id=G-4CS8T9LDC8` |
| Скролл | нативный, `scroll-behavior: smooth` | никакого scroll-hijack |
| Тема | класс `body.light` / `body.dark` | |

Итого: **никакого фреймворка-тяжеловеса**. Весь «вау» сделан на CSS-переходах,
IntersectionObserver и одном фрагментном шейдере.

## Приёмы, из которых состоит дизайн

1. **Bento-раскладка.** Контейнер `max-width: 1800px`, `padding: 0 40px`,
   всё разложено на карточки `border-radius: 30px` с зазором `0.6em`.

2. **Вырез (notch) в карточке.** Логотип и хедер «выгрызены» из hero-карточки:
   блок залит цветом фона, `border-radius: 0 0 30px 0`, плюс два элемента с
   вогнутыми скруглениями по краям. Тот же приём — для текста в левом нижнем
   углу hero.

3. **Стеклянная пилюля навигации.**
   `backdrop-filter: blur(10px) saturate(200%)` + полупрозрачный фон +
   `1px` бордер + мягкая тень.

4. **Hero = шейдер.** Полноэкранный фрагментный шейдер (flow field на fbm),
   растянутый на 1800px и подкрашенный `filter: hue-rotate(330deg)`.

5. **Работы — список, а не сетка.** Заголовки `6rem`, тонкая линия снизу,
   на ховере текст уезжает на `1em` вправо, курсор подменяется на SVG-стрелку
   в круге (`cursor: url(data:image/svg+xml…)`).

6. **Скиллы — гигантский текст с врастающим видео.** `.video-wrapper` имеет
   `width: 0`, при попадании в вьюпорт получает `width: 12rem`, видео внутри
   едет `scale(0) → scale(1)`. Строка физически раздвигается.

7. **Blur-in на скролле.** `.blur { filter: blur(10px) }` →
   `.blur-visible { filter: blur(0) }`, переход 1s.

8. **Contact — свет, а не картинка.** Видео-градиент под
   `filter: blur(10px) scale(1.2)` + сверху `<canvas class="grain">` с
   плёночным зерном.

9. **Мобильное меню** — фиолетовая шторка `#5C54F9` с несимметричным радиусом
   `30px 0 30px 30px` и «язычком» через `::before`.

## Что я взял, а что сделал иначе

**Взял:** bento + радиус 30, notch, стеклянная пилюля, шейдерный hero,
список работ вместо сетки, врастающее медиа в скиллах, blur-in, зерно на
contact.

**Сделал иначе и почему:**

- **Свой шейдер.** Написал с нуля: value-noise fbm + два прохода domain
  warping, палитра из четырёх стопов, зерно прямо в шейдере (убирает бандинг).
  Копировать их GLSL нельзя, да и палитра нужна своя.
- **Без Swiper.** Их два маленьких слайдера тянут ~140 KB. Заменил хуком
  `useCarousel` на 40 строк.
- **TypeScript** вместо JS.
- **`data-theme` на `<html>` + инлайн-скрипт** вместо класса на `body` —
  тема применяется до первой отрисовки, нет мигания.
- **Превью работ за курсором** вместо простого сдвига текста — для дизайнера
  показать скриншот важнее, чем для креативного разработчика.
- **`woff2`** вместо `ttf`, когда дойдёт до шрифта.
- **Пауза рендера**, когда карточка вне вьюпорта и когда вкладка в фоне —
  у них шейдер крутится всегда.
